DXMirror 0.2.0 – AirPlay-Empfänger für Windows
==============================================

DEUTSCH
-------
DXMirror zeigt den Bildschirm deines iPhones (oder iPads) mit Ton auf dem Windows-PC an.

Voraussetzungen
- Windows 10 (ab Version 1809) oder Windows 11, 64 Bit
- PC und iPhone im selben WLAN/Netzwerk (kein Gast-WLAN), Netzwerkprofil „Privat“
- Apple Bonjour (kostenlos). Ist es nicht installiert, zeigt DXMirror einen Hinweis mit
  Download-Knopf. Download: https://support.apple.com/de-de/106380

Installation
1. DXMirror-Setup-0.2.0-x64.exe starten.
2. Erscheint „Der Computer wurde durch Windows geschützt“ (SmartScreen): auf „Weitere
   Informationen“ und dann „Trotzdem ausführen“ klicken. Das kommt, weil das Programm nicht
   digital signiert ist.
3. Sprache wählen (Deutsch/English) und die Windows-Abfrage nach Administratorrechten mit „Ja“
   bestätigen (nötig für den Programmordner und die Firewall-Regeln).
4. Den Haken bei „Windows-Firewall-Regeln anlegen“ aktiviert lassen.

Benutzung
- DXMirror starten. Auf dem iPhone: Kontrollzentrum → Bildschirmsynchronisierung →
  „DXMirror – <PC-Name>“ wählen.
- Aufnahmen (MP4 mit Ton) über den Aufnahme-Knopf in der Übersicht; Speicherort: Videos\DXMirror.
- Findet das iPhone den PC nicht: auf die gelbe Warnung in der Übersicht achten (z. B. blockiert
  TeamViewer die Erkennung) und unter „Diagnose“ die Firewall-Regeln einrichten.

Deinstallation: Windows-Einstellungen → Apps → DXMirror → Deinstallieren.


ENGLISH
-------
DXMirror shows your iPhone's (or iPad's) screen with sound on your Windows PC.

Requirements
- Windows 10 (1809 or later) or Windows 11, 64-bit
- PC and iPhone on the same Wi-Fi/network (no guest Wi-Fi), network profile "Private"
- Apple Bonjour (free). If it is missing, DXMirror shows a notice with a download button.
  Download: https://support.apple.com/en-us/106380

Installation
1. Run DXMirror-Setup-0.2.0-x64.exe.
2. If "Windows protected your PC" (SmartScreen) appears, click "More info" and then "Run anyway".
   This appears because the program is not digitally signed.
3. Choose the language (Deutsch/English) and confirm the Windows administrator prompt with "Yes"
   (needed for the program folder and the firewall rules).
4. Keep "Create Windows Firewall rules" checked.

Usage
- Start DXMirror. On the iPhone: Control Center → Screen Mirroring → "DXMirror – <PC name>".
- Record (MP4 with sound) with the record button on the dashboard; saved to Videos\DXMirror.
- If the iPhone does not find the PC: check the yellow warning on the dashboard (e.g. TeamViewer
  blocking discovery) and set up the firewall rules under "Diagnostics".

Uninstall: Windows Settings → Apps → DXMirror → Uninstall.
